SelectEnglish

在阅读中理解英文，积累表达。

关闭后页面上不再出现小圆钮和小窗。
历史只存在本机（最多 300 条），可在「历史」标签里查看、导出或清空。
没填 API Key 时也能先看效果：选中英文会返回一份固定示例，不消耗任何接口。 填好 Key 后关掉它即可真实分析。
OpenAI 兼容的 chat/completions。填到 /v1 或直接填完整地址都可以。
只保存在本机浏览器存储中（chrome.storage.local），不会写入代码、不会上传；导出/同步请自行留意。
温度 = 模型回答的随机程度：0 最稳定、每次结果几乎一样；越大越发散、措辞越花样。 查词这种任务要的是稳定，建议 0–0.5，默认 0.3。留空也会回到默认。

这是什么

SelectEnglish 原本是 macOS 原生 App（Swift/AppKit + Force Touch 触控板）。本扩展是它的浏览器版复刻： 选中英文后弹出牛皮纸小窗，按「生词 → 整句解释 → 固定表达」的顺序给出结果，逻辑与提示词对齐原项目， 面向大学英语六级阅读者（优先六级及以上词汇、专业词、熟词僻义，略过基础高频词）。

说明

本扩展不内置任何 API Key，AI 能力由你自己配置：填一个 OpenAI 兼容接口（DeepSeek 等）的地址、 模型名和你的 Key。没配之前可以勾选「演示模式」先看效果，不联网、不花钱。

怎么用

  • 用鼠标选中一段英文 → 出现「译」小圆钮 → 点它；或在选中文本上点右键 →「查询选中的英文」。
  • 快捷键：Alt + Shift + E 直接查询当前选区。
  • 小窗里：🔊 朗读、☆ 收藏、⧉ 复制、✕ 或 Esc 关闭；每个生词后面的小喇叭单独读这个词。
  • 按住小窗顶部或底部可以拖动，本次会话内会记住摆放位置；跟随系统深色模式自动切换配色。
  • 「历史」标签里能回看最近的查询，收藏和历史都可以导出 Anki CSV（导入时勾选「允许 HTML」）或 Markdown。

隐私

  • 只有你主动查询时，才会把选中的英文、所在句子、网页标题发送给你自己配置的 AI 接口。
  • API Key 存放在扩展自身的本地存储里（设置页与后台可读）；网页脚本和页面里的代码读不到。
  • 收藏和查询历史保存在本机，不上传，可在设置里关闭历史记录或随时清空。接口地址、模型、Key 全部由你自填，不经过任何第三方服务器。
